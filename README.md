VERO — Luxury Real Estate Website

VERO is a modern luxury real estate website concept built to reflect the elegance, discretion, and editorial sophistication of high-end London property firms.

Designed with a focus on smooth motion, refined typography, and immersive storytelling, the website presents properties, agents, and brand identity through carefully crafted scroll-based experiences.

🔗 Live Website:
https://vero-ten.vercel.app/

🧰 Tech Stack
💻 Frontend

• HTML5
• CSS3
• JavaScript (ES6+)
• React (Vite)

🎨 Styling

• Tailwind CSS v4
• Custom CSS
• Custom font integration (Cinzel, Lora)
